# Around the U.S. Full Stack

## Descipcion

around the U.S. es un proyecto web full-stack donde los usuarios pueden crear una cuenta,iniciar sesión de forma segura, editar su perfil, actualizar su avatar, publicar tarjetas de imágenes, dar me gusta a las tarjetas y eliminar sus propias publicaciones.

El proyecto integra un frontend en React con un backend en Node.js/Express conectado a una base de datos MongoDB. La autenticación de usuarios se maneja usando JSON Web Tokens (JWT), lo que permite rutas protegidas y acceso seguro a los recursos de los usuarios.

## Características

- Registro y inicio de sesión de usuario
- Autenticación JWT
- Rutas protegidas
- Editar información del perfil
- Actualizar avatar del perfil
- Crear nuevas tarjetas de imagen
- Dar me gusta y quitar me gusta a las tarjetas
- Eliminar tarjetas creadas por el usuario autenticado
- Interfaz responsiva
